# Ahmed Mounir portfolio

Public website: https://ahmedelmoner-arch.github.io/

This repository contains the self-contained public portfolio page. GitHub Pages publishes the root of the `main` branch.

## Update the public page

1. Open the portfolio and choose **تعديل بياناتي**.
2. Save the edits, then choose **تنزيل نسخة محدّثة**.
3. Rename the downloaded file to `index.html`.
4. Open this repository on GitHub, choose **Add file → Upload files**, upload the updated `index.html`, and commit to `main`.
5. Wait for the Pages deployment to finish. The same public URL will show the update.

Edits in the page's editor are stored on the visitor's device. Publishing the updated HTML to this repository updates the shared public page.
