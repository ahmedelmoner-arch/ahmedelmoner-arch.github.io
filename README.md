# Ahmed Mounir portfolio

Public website: https://ahmedelmoner-arch.github.io/

This repository contains the public visitor page. GitHub Pages publishes the root of the `main` branch. Editing controls are available in the owner's local editing copy.

## Update the public page

1. Open your local editing copy of the portfolio and choose **تعديل بياناتي**.
2. Save your edits, then choose **تنزيل نسخة محدّثة**. The downloaded file is ready for visitors and contains no editing tools.
3. Rename the downloaded file to `index.html`.
4. On GitHub choose **Add file → Upload files**, upload the updated `index.html`, and commit to `main`.
5. Wait for the Pages deployment to finish. The same public URL will show the update.

Keep your local editing copy for future changes. The public page does not load visitor-specific saved edits.
